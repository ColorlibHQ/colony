# create-colony-admin

Scaffold [Colony](https://github.com/ColorlibHQ/colony) — a free, bilingual React
admin dashboard on Ant Design v6, Vite 8 and TypeScript. No meta-framework, no
prerelease dependencies.

```bash
pnpm create colony-admin my-app
cd my-app
pnpm install
pnpm dev
```

Also works with npm, yarn and bun:

```bash
npm  create colony-admin my-app
yarn create colony-admin my-app
bun  create colony-admin my-app
```

Requires Node 20.19+ or 22.12+, and git.

Documentation, in English and 简体中文: **[colony.colorlib.com](https://colony.colorlib.com)**
Live demo: **[colony-demo.colorlib.com](https://colony-demo.colorlib.com)**
